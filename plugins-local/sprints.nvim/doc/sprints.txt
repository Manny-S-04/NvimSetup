SETUP                                                        *sprints-setup*

Zoho uses OAuth. Create a Self Client at https://api-console.zoho.<dc>,
generate a code with the scopes listed in the README, exchange it for a
refresh token, then set:

  ZOHO_DC              data centre: com, eu, uk, in, au, jp, ca, sa, cn
  ZOHO_CLIENT_ID       Self Client id
  ZOHO_CLIENT_SECRET   Self Client secret
  ZOHO_REFRESH_TOKEN   refresh token (doesn't expire unless revoked)

Optional: ZOHO_SPRINTS_TEAM, ZOHO_SPRINTS_PROJECT, and ZOHO_SPRINTS_USER (or
ZOHO_EMAIL to look your user id up). Run |:checkhealth| sprints to verify.

==============================================================================
CONFIGURATION                                               *sprints-config*

>lua
  require("sprints").setup({
    dc = "eu",
    team_id = nil, project_id = nil, user_id = nil, email = nil,
    page_size = 100,
    item_url = "https://sprints.zoho.{dc}/team/{team}#itemdetails/P{project}/I{item}",
    api_url = nil, accounts_url = nil, -- host overrides (mock server, proxy)
    open_cmd = "split",       -- "split" | "vsplit" | "tabnew" | "edit"
    keymaps = { item = { ... }, list = { ... } }, -- false disables a key
  })
<
Explicit options win over environment variables, which win over defaults.
`item_url` placeholders: {dc} {team} {project} {sprint} {item} {no}.

==============================================================================
COMMANDS                                                  *sprints-commands*

:SprintsMine             Your items in the active sprint(s).
:SprintsBoard            Active sprint(s) grouped by status.
:SprintsBacklog          Items in the project backlog.
:SprintsNew              New item; :w creates.
:SprintsItem [NO]        Open an item (I12, 12, PRJ-I12; default: under cursor).
:SprintsSearch {words}   Items whose title has every word.
:SprintsSprint [pick]    Items in the active sprint(s), or pick any sprint.
:SprintsProject          Switch project for this session.
:SprintsRefresh          Refresh the current item buffer.
:SprintsRaw {what}       Raw API response (teams, projects, project,
                         sprints, statuses, users, itemsearch {value}
                         [itemid|name]).
:Sprints                 Help.

List buffer: <CR> open, n new, b board, m only mine, yk/yu copy key/link,
gx browser, r refresh, g? help.
Item buffer: s status, e edit (:w saves), c comment (:w posts), a add/remove
me, o add/remove owner, A remove all owners, p priority, yk/yu copy key/link,
gx browser, gR raw response, r refresh, g? help.

==============================================================================
EDITING                                                     *sprints-edit*

`e` in an item and |:SprintsNew| open a buffer: "# Title" on line 1, then
"Field: value" lines, then "---" and the description in markdown. Allowed
values show as virtual text. :w sends only the changed fields.
